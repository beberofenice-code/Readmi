# Story Arcs

Pick one. Slide counts are proportions of the slide budget.

## 1. Problem → Stakes → Turn → Proof → Ask  (default; pitches, proposals)
Hook 10 % · Problem/villain 20 % · Stakes ("what happens if we don't") 10 % ·
Turn (the idea) 15 % · Proof 30 % · Ask + callback 15 %

## 2. What Is → What Could Be (Duarte "sparkline"; keynotes, vision talks)
Alternate "today's reality" and "the better future" slides 3–5 times, ending
on the "new bliss" image + ask. Tonal contrast does the engagement work —
cooler palette for *what is*, warmer for *what could be*.

## 3. Mystery → Clues → Reveal (teaching, data stories)
Open with a puzzle the audience can't yet answer. Each section adds a clue
(`predict-then-reveal` works well). Answer revealed at 75 % mark; then apply it.

## 4. Hero's Journey (case studies, customer stories)
Ordinary world → challenge → mentor/tool (your product/idea) → trial →
transformation → lesson for the audience.

## 5. Countdown / Listicle (social, quick talks ≤ 5 min)
"5 mistakes that…" — number every slide big, save the best for #1, recap,
ask. Each item = one `assertion-evidence` slide.
